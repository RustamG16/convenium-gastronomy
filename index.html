Häufige Fragen

Ist das eine fertige Vorlage?

Nein. SAVRA zeigt eine Richtung; Ihre Website wird für Ihr Lokal gestaltet.

Kann meine Reservierung eingebunden werden?

Vorhandene Reservierungs- oder Bestelllinks ja. Weitere Integrationen hängen vom Anbieter ab.

Was kostet eine Website?

Ab € 500 netto für eine einseitige Website – der Launch-Preis für die ersten zehn Lokale. Den Endpreis bestätigen wir vor dem Start schriftlich.

Ist SAVRA ein Kundenprojekt?

Nein. SAVRA ist eine Konzeptwebsite von Convenium, kein Kundenauftrag.
